# Automation QA - Preentrega

Proyecto de automatización de pruebas utilizando Selenium WebDriver, Pytest y Python sobre el sitio de pruebas [SauceDemo](https://www.saucedemo.com/).


## Tecnologias usadas
-Python
-Selenium
-Pytest
-Git
-Github

## Instalación

Instalar las dependencias:

```Python
python -m pip install pytest
```

```Python
python -m pip install pytest-html
```

## Ejecución de las pruebas
```Python
pytest
```

## Casos de prueba

-Login exitoso: Validación de ingreso con credenciales válidas y verificación de la URL de inventario.

-Agregar producto al carrito: Interacción con los elementos de la tienda para sumar productos.

-Verificar producto en el carrito: Comprobación de que el artículo seleccionado se encuentre correctamente listado.
